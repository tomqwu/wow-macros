# 魔兽世界宏

[English](README.md)

本仓库用于保存从实际对话中整理出的、按游戏版本和职业组织的《魔兽世界》宏。

## 当前版本

| 版本 | 状态 | 浏览 |
| --- | --- | --- |
| TBC Classic / TBC Anniversary | 使用中 | [职业与宏](tbc/README_zhCN.md) |

目前仅整理 TBC 内容。其他游戏版本应使用独立的顶层目录，避免混用不兼容的宏。

## 生成流程

使用仓库中的 [TBC 宏生成 Skill](skills/build-tbc-macros/SKILL.md)，根据玩家等级、天赋配置、关键天赋、技能循环、职责、玩法、目标优先级和客户端信息生成精简宏组合。

每个职业使用两个互相链接的页面：

- `README.md`：默认英文页面，保存 `enUS` 宏。
- `README_zhCN.md`：简体中文页面，保存对应的 `zhCN` 宏。

两个页面必须使用相同的玩家模型、稳定宏 ID、状态、命令结构和验证记录。单语言来源资料保留在对应语言页面的待处理区，直到补齐并测试另一语言版本。

## 文件约定

- 默认英文职业页面：`<version>/classes/<class>/README.md`
- 简体中文职业页面：`<version>/classes/<class>/README_zhCN.md`
- 两个文件顶部必须互相链接。
- 尚未验证的跨会话资料保存在来源语言页面的待处理区，并明确标记状态。
- 可能随版本变化的行为必须记录游戏版本或补丁及验证日期。
- 每个宏在两个页面使用相同的用途标题和稳定 ID。
- 对应的 `enUS` 与 `zhCN` 宏必须保持相同功能和命令结构。
- 不为每个宏单独创建文件。

客户端语言与验证规则请参阅 [LOCALIZATION.md](LOCALIZATION.md)。
