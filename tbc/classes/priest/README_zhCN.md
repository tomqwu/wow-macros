## 技能循环与天赋模型

### 玩家循环

- 起手：英文来源提供暗影首领与副本持续伤害起手；治疗与 PvP 起手尚未规范化。
- 持续优先级：来源记录吸血鬼之触、暗言术：痛、心灵震爆、精神鞭笞、省蓝规则和多目标限制。
- 冷却 / 应急：来源涉及心灵专注、暗影魔、渐隐术、退出暗影形态应急治疗、痛苦压制和能量灌注。

### 宏设计机会

- 可针对确定的牧师配置生成暗影目标、治疗鼠标指向、驱散或竞技场小队 / 焦点控制宏。
- 应从玩家循环中提炼目标便利功能，不隐藏持续伤害刷新与引导时机。

### 明确保留手动操作

- 持续伤害刷新、精神鞭笞打断时机、法力决定、治疗分诊和完整暗影优先级保持手动。
- 互斥的神圣、戒律与暗影天赋不会被当作同一套玩家配置发布。

## 宏组合

尚无双语宏。需要先选定一个当前牧师配置、确认 `zhCN` 法术名称，并在两个客户端版本中测试后才能提升状态。
