## 技能循环与天赋模型

### 玩家循环

- 起手：未提供。
- 持续优先级：未提供。
- 冷却 / 应急：停止当前施法，必要时取消形态，激活自然迅捷，然后对预定友方单位立即施放已学会的最高等级治疗之触。

### 宏设计机会

- 将明确提供的自然迅捷应急步骤与清晰的友方目标优先级组合。
- 提供一个可从团队框架鼠标指向回退至友方当前目标的版本，以及一个跳过当前目标的竞技场安全版本。
- 先取消形态，以便从熊、猎豹、旅行或树形态使用同一个应急按键。

### 明确保留手动操作

- 未提供常规恢复治疗循环，因此不作推断。
- 冷却或增益状态仍需玩家自行判断；宏不能声称会判断自然迅捷是否可用。

## 宏组合

### 恢复 — 自然迅捷应急治疗

- ID: `restoration-natures-swiftness-healing-touch`
- 状态: `ready-for-client-test`
- 来源: 已提供的自然迅捷应急治疗步骤与恢复天赋选择
- 用途: 停止当前施法，并从任意形态执行应急治疗
- 目标: 存活友方鼠标指向、存活友方当前目标、玩家自己
- 限制: 如果自然迅捷不可用，治疗之触可能开始正常读条；未提供确切客户端版本

#### 宏命令

```lua
#showtooltip 自然迅捷
/stopcasting
/cancelform
/cast 自然迅捷
/cast [@mouseover,help,nodead][@target,help,nodead][@player] 治疗之触
```

### 恢复 — 自然迅捷应急治疗（竞技场安全）

- ID: `restoration-natures-swiftness-healing-touch-arena-safe`
- 状态: `ready-for-client-test`
- 来源: 同一应急步骤，并应用所要求的竞技场安全目标限制
- 用途: 进行应急治疗，同时避免误用友方当前目标
- 目标: 存活友方鼠标指向、玩家自己；有意跳过当前目标

### 使用说明

键盘绑定的鼠标指向宏可在 Cell 和其他安全团队框架上使用。请把宏放到动作条并绑定该栏位。在 macOS 上，可以用 Logi Options+ 将 Logitech MX 侧键映射到 `F8` 或 `F9` 等未使用按键，再在魔兽世界中绑定该按键。

自然迅捷冷却时，此宏可能开始正常读条施放治疗之触。请保留自然迅捷的提示图标，并只在技能可用时使用。如果本地化名称被客户端拒绝，请从对应客户端的法术书中按 Shift 点击插入准确名称。
