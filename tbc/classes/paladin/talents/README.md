# Paladin talents

TBC talent trees: Holy, Protection, Retribution.

Store one TBC talent build per Markdown file. Use the talent tree and build purpose in a lowercase kebab-case filename.

Example: `<specialization>-<build>.md`

Include explanation sections for:

- `English (enUS)`
- `简体中文 (zhCN)`
- `繁體中文 (zhTW)`

Record the exact TBC version or build, verification date, intended content, point allocation, talent-calculator source, and any usage notes. Include an import string only when the target TBC client supports one.

Follow the [client localization guide](../../../../LOCALIZATION.md).
