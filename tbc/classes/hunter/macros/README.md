# Hunter macros

TBC talent trees: Beast Mastery, Marksmanship, Survival.

Add each client-sensitive macro as a matching locale set:

- `<specialization>-<purpose>.enUS.macro` for English
- `<specialization>-<purpose>.zhCN.macro` for Simplified Chinese

Use an unsuffixed `<specialization>-<purpose>.macro` only for client-language-neutral content.

Keep behavior identical across locale variants and verify localized game names before publishing.

Follow the [client localization guide](../../../../LOCALIZATION.md).
