Opening a class folder displays its English `README.md` by default. Use the locale link at the top to open `README_zhCN.md`. Matching macros use the same stable ID and command structure across both pages.

Imported session material stays on its source-language page with an unverified status until it is normalized and tested.

See the repository [localization guide](../LOCALIZATION.md) for publishing and verification rules. Use the [TBC Macro Builder skill](../skills/build-tbc-macros/SKILL.md) to add or normalize player-specific macro sets.
